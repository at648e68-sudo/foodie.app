Foodie — Purple & Baby Pink Food Delivery Demo
This is a mobile-first web app starter for the Foodie concept.
Run on your phone
Upload this project to a GitHub repository.
Open web/index.html in a browser to preview locally, or deploy the web folder with GitHub Pages.
The included demo supports browsing sample restaurants, menus, cart quantity changes, demo checkout, and local order history.
Important
This is a front-end demo, not a live food-delivery business yet. Orders and profile are stored only in the current browser (localStorage). The UPI option is a demo label only; it does not take payments. Sample restaurants and prices are placeholders.
Needed for production
Firebase Authentication and Firestore/Storage with security rules
Restaurant partner and delivery partner authentication/portals
Server-side order creation, pricing validation, notifications and dispatch
Payment gateway merchant account and server-side verification
Maps/driver location integration and privacy/consent handling
Admin panel, legal policies, support/refunds, restaurant onboarding
